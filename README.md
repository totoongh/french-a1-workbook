# Französisch A1 Workbook

Interaktives Französisch-A1-Lernstudio: 17 Module, 510 Wortkarten, 200 Satzkarten, Wort- und Satztrainer mit Leitner-System.

Rein statische React-App – der Lernfortschritt wird nur im `localStorage` des Browsers gespeichert.

```bash
npm install
npm run dev
```

Jeder Push auf `main` wird per GitHub Actions auf GitHub Pages veröffentlicht.
